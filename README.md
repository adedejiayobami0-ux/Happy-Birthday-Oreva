# Happy Birthday Oreva — GitHub Pages site

This folder contains the updated birthday website for Oreva.

## Upload to GitHub Pages
Upload the contents of this folder so your repository root looks like this:

- `index.html`
- `styles.css`
- `script.js`
- `README.md`
- `assets/`

Do **not** upload the outer folder alone.

## GitHub Pages settings
In GitHub:
1. Open **Settings → Pages**
2. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/(root)`
3. Save and wait a minute or two.

## Birthday wall note
The “Our Little Instagram” birthday wall works on a static GitHub Pages site using the visitor's browser storage.
That means messages entered there stay in the browser/device that posted them.

If you want **shared live messages from everyone**, connect the form later to a small backend such as Supabase, Firebase, or Formspree.
