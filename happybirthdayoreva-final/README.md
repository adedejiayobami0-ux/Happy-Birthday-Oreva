# Happy Birthday Oreva — GitHub Pages site

This ZIP is already structured correctly for GitHub Pages: **`index.html` is at the root**.

## Upload to your existing `happybirthdayoreva` repository

1. Unzip this folder.
2. In GitHub, open your `happybirthdayoreva` repository.
3. Upload **all of the contents** of this folder directly to the repository root (not inside another folder).
4. Replace the old files if GitHub asks.
5. Make sure **Settings → Pages → Deploy from a branch → `main` → `/(root)`** is selected.
6. Commit the changes. GitHub Pages usually refreshes within a few minutes.

Your repo root should look like:

```
index.html
styles.css
script.js
README.md
assets/
  photos/
  video/
```

## Privacy note
The photos and videos are embedded as local site assets. If the GitHub repository is public, the media on the published website will also be publicly accessible.
